# UnoCSS Usage

## いつ使うか
- UnoCSSを導入・移行したい時
- デザイントークンとユーティリティの整合性を保ちたい時

## 参照ルール（最優先）
- `.cursor/rules/01-design-system.mdc`

## 実行手順
1. **プリセット選定**: 使用するプリセットと拡張方針を決める
2. **スキャン範囲**: 対象ディレクトリと除外を明確化
3. **トークン設計**: 色/余白/影を既存ルールと整合させる
4. **ショートカット**: 再利用性の高い組合せを命名
5. **検証**: 生成量/ビルド時間/競合を確認

## チェックリスト
- 既存デザインシステムと矛盾しない
- ビルドサイズが許容範囲
- 禁止表現が混入していない

## 出力テンプレ
1. 採用プリセット
2. スキャン範囲
3. トークン設計方針
4. 運用ルール
